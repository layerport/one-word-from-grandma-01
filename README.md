# One Word From Grandma

Entry for the make.fun bounty
[One Word From Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16).

The entry is a single word: **ROBUT**.

It is the word "robot" the way a grandma actually texts it — one letter
slipped, caps on because she never found the lowercase key, warm and a
little baffled, and funny the moment you read it with no caption at all.

## How to run

```sh
python3 main.py
```

This writes the word to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

## The word

`ROBUT` — 5 characters, one word, no spaces, no trailing newline.
It is deterministic: every run writes the exact same bytes.
